# Instruções do projeto

- Sempre leia `roadmap.json` (raiz do projeto) no início de qualquer tarefa de desenvolvimento neste repositório. Ele contém o checklist de features (implementadas e pendentes) e o log de progresso do sistema. Mantenha esse arquivo atualizado: marque features como `"Implementada"` quando concluídas e registre comentários breves em `log` conforme o desenvolvimento avança.
- **Ícones e interface visual**: Sempre utilize a biblioteca `lucide-react` para todos os ícones da interface. **Nunca utilize emojis** nos componentes, botões, abas ou textos da interface do usuário.
