# Instruções do projeto

- Sempre leia `PROJETO_E_ROADMAP.md` e `roadmap.json` (raiz do projeto) no início de qualquer tarefa de desenvolvimento neste repositório. Eles contêm o checklist de features (implementadas e pendentes) e a documentação mestre unificada do sistema. Mantenha esses arquivos atualizados: marque features como `"Implementada"` quando concluídas e registre comentários breves em `log` conforme o desenvolvimento avança.
- **Ícones e interface visual**: Sempre utilize a biblioteca `lucide-react` para todos os ícones da interface. **Nunca utilize emojis** nos componentes, botões, abas ou textos da interface do usuário.
